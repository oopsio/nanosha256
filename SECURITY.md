# Security Policy

## Supported Versions

The following versions are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.x  | :x:                |

## Reporting a Vulnerability

We take the security of **nanosha256** seriously. If you believe you have found a security vulnerability, please do NOT create a public issue. Instead, report it privately.

**To report a vulnerability:**
1. Send an email to the project maintainers (as listed in README or project meta).
2. Briefly describe the potential vulnerability.
3. Provide a Proof of Concept (PoC) or clear steps to reproduce.
4. We will respond within 48-72 hours to acknowledge and discuss next steps.

---

### Disclosure Policy
We follow a 90-day disclosure cycle for security vulnerabilities. After we have fixed the vulnerability, we will release a security advisory and credit the researcher.

Thank you for helping us keep **nanosha256** safe for everyone.
